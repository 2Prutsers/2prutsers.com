# Video Debriefs Media Placeholders

These files are placeholders for `/video-debriefs`.

- `hero-poster.svg`: Replace with a poster frame from the walkthrough video.
- `walkthrough-placeholder.mp4`: Replace with a 60-90 second app walkthrough.
- `import.png`: Screenshot of SD-card or folder import.
- `review.png`: Screenshot of trim, markers, metadata, and clip review.
- `present.png`: Screenshot of fullscreen presentation mode.

Recommended video export: 1920x1080 MP4, H.264, under 25 MB.
